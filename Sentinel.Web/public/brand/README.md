# Sentinel — identidade Harpia

Identidade vetorial original criada para a branch V51. Não são arquivos oficiais fornecidos por um estúdio ou por um titular de marca. O símbolo usa o penacho, o disco facial e o bico da harpia brasileira, com olhos em âmbar natural e plumagem fria.

- `harpy-symbol.svg`: símbolo colorido, aplicação principal, favicon e tamanhos reduzidos.
- `harpy-monochrome.svg`: símbolo em `currentColor`, com recortes para olhos e bico.
- `sentinel-horizontal-dark.svg` / `sentinel-horizontal-light.svg`: assinaturas para fundos escuros/claros.
- `sentinel-vertical.svg`: assinatura vertical para fundo escuro.

Os SVGs são locais, sem scripts, fontes remotas ou dependências de imagem. As assinaturas usam Segoe UI/Arial disponíveis no sistema. O aplicativo usa o símbolo e texto HTML para manter a leitura acessível.

Na operação, priorizar nomes, estados e evidências. Reservar a marca ampliada à entrada e à visão geral. Escudos existentes representam controles de segurança e não substituem o símbolo da marca.
